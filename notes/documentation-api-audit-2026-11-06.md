## API verification

The API snapshot committed by the engine reports 130 Epok runtime headers and 53 PsyQo headers, 719 types, 3,161 callable declarations and 3,746 properties. It records no extraction diagnostics. The previous website snapshot contained 126 modules, 442 types, 1,883 callables and 2,065 properties.

`tools/verify-api-sources.mjs` compares the recorded SHA-256 of each runtime header with the engine Git blob, and each SDK header with the pinned Nugget Git blob. SDK files accept the original Windows CRLF checkout form as well as Git's blob form. It also checks SDK revision agreement and rejects extraction diagnostics. This verifies the input identity, not the semantic completeness or correctness of every extracted declaration.

The catalog and its examples are generated by the engine's committed generator; no new extraction or compiler build was run. Examples and general guidance are generated sketches, not independently compiled programs or guarantees of safety. The API interface now states that explicitly and links to the source contract.
